# 自定义头像与动作

回到 [项目介绍](../README.md) · [开发与验证](development.md)。

入口：工作区设置 → 外观 → 配色与自定义头像；也可从连接页左上角的外观菜单进入。六种配色、界面皮肤和深浅色可以分别设置，立即生效。

1. 选择角色主题，在照片或文件中导入头像。建议使用正方形 PNG / JPEG；非正方形静态图会居中裁切展示。
2. 导入 GIF / APNG，或按下面的模板生成 2×2 四帧图并导入。四帧图按左上、右上、左下、右下拆分。
3. 在设置中检查静态头像和动作预览，调整播放速度。只导入头像时不会混用默认角色的动作；只导入动作时第一帧成为静态头像。

单文件最多 16MB，动图最多 48 帧。PNG 可保留透明背景，建议四帧图边长至少 1024 像素、偶数且无边距。GIF 建议经“文件”导入，避免照片输出成静态图。

素材只保存在本机，重启后仍可使用，不会替换 iPad 桌面图标。恢复默认会清除自定义头像和动作。系统“减少动态效果”或进入后台时暂停播放；对话中只有当前回合最新回复使用动作，左上角无 Logo。

## 支持的素材

| 导入类型 | 处理方式 |
| --- | --- |
| 静态头像 | 从照片或文件选择图片，自动缩小并按头像区域展示。 |
| GIF / APNG | 保留动作帧与原有时序，可再调整播放速度。 |
| 2×2 四帧图 | 自动按阅读顺序拆分；无需另做 GIF。 |

恢复默认不删除照片库或原始文件，只重置 App 保存的头像与动作。自定义头像和动作不替换桌面图标。

## 头像提示词

附上你想保留的角色参考图，替换方括号中的描述后使用。

```text
请根据我上传的参考图制作一个应用内角色头像。
角色描述：[填写外貌、服饰、耳麦等特征]
画风：[填写喜欢的画风]
背景：[纯色或透明背景]
输出一张 1:1 正方形图片，建议 1024×1024。脸部和上半身清晰，主体居中，头部占画面约 75%，保留头饰与耳麦的完整轮廓，四周留少量安全边距。小尺寸下也能辨认表情。保持参考角色身份，不添加文字、水印、边框或光效。
```

## 四帧思考动作提示词

附上已选定的头像作为参考图，保持身份与画风。

```text
请以我上传的头像为唯一角色参考，制作一张用于循环思考动画的四帧动作图。
输出一张 1:1 正方形图片，建议 1536×1536，严格按 2 列×2 行排成四个等大的正方形画面。没有外边距、格间距、分隔线、编号或文字。
保持四帧中角色身份、画风、脸部比例、发色、头饰、服装、耳麦、背景和光照一致，镜头与头部位置、大小固定。
阅读顺序为左上→右上→左下→右下：
1. 眼睛睁开，视线略向上，手抬向下巴。
2. 手指轻轻托住下巴，露出思索表情。
3. 保持托腮姿势，轻轻闭眼眨眼。
4. 睁眼，手开始放下，动作自然回到第一帧。
动作与表情变化应在小头像里清晰可见。不要整体漂浮、旋转、缩放，不加光环、粒子或思考气泡，不改变角色造型。每帧内保留完整头饰与动作手部，背景与头像一致。[替换上面的动作描述也可以制作自己的循环动作。]
```
