# Code Pax

通过 SSH 在 iPad 上使用远端 Codex 的原生客户端。可以继续服务器上的开发对话、查看代码执行和文件结果，也可以直接打开交互式终端操作项目。

当前 App 版本 **0.14.1**，支持 **iPadOS 17 及以上**。工程、Target 和 Scheme 均为 **`CodePax`**，仓库为 [raycao871218/code-pax](https://github.com/raycao871218/code-pax)。

## 当前功能

| 功能 | 使用方式 |
| --- | --- |
| 服务器连接 | 保存多台 SSH 服务器，以卡片快速连接；可选钥匙串密码保存、主机指纹核对、断线自动重连。一次连接一台服务器。 |
| 项目与聊天 | 按项目分组，同步同一 SSH 用户、同一 Codex Home 下的 CLI / VS Code / App Server 历史；支持搜索、新建、重命名、置顶、归档与恢复。 |
| 消息与任务 | 发送后立即显示送达状态；草稿按服务器和会话保存。发送与停止共用按钮，命令输出默认折叠，完成后显示状态及未读提醒。 |
| 模型与权限 | 从服务器读取可用模型和推理强度；提供默认权限与 Full Access，选择在后续任务中生效。 |
| Markdown 与长内容 | 回复支持常见 Markdown；长消息、命令输出与差异可分段读取、复制。打开 Markdown 文件可切换阅读与源码。 |
| 附件与文件 | 从照片、文件、粘贴或拖放添加附件；上传有进度，已发送附件和项目文件链接可预览、保存或分享。 |
| 全屏终端 | 从当前项目目录打开交互式 SSH PTY，支持中文、ANSI 彩色输出、硬件键盘、控制键、窗口缩放、调字号与清屏。收起后保留会话。 |
| Usage | 连接并准备好工作区后自动检测，之后每分钟刷新。输入区小图标按最低剩余额度显示绿色、黄色或红色，面板可查看额度与 token 明细。 |
| 外观与角色 | 经典工作台 / 角色主题两套布局，六组配色，支持深色、浅色和跟随系统；角色头像及动作可自定义，附制作引导和提示词模板。 |

输入区默认选择 **Full Access**：Codex 命令和文件操作不逐项请求审批。可切回默认权限，服务器组织策略仍可能限制实际能力。终端直接使用 SSH 账号的权限，不经过 Codex 审批流程。

## 快速开始

### 1. 准备环境

- **Mac**：安装能解析仓库所锁定 Swift Package 依赖的 Xcode。当前验证环境为 **Xcode 27.1（27A9275）**；旧版 Xcode 可能无法解析依赖使用的 Swift 工具链版本。
- **iPad**：iPadOS 17 或更新系统；也可以先用 iPad 模拟器测试。
- **Linux 服务器**：提供可达的 SSH 密码登录、Python 3.9+，以及已完成登录、支持 `codex app-server` 的 Codex CLI。
- **网络**：iPad 能访问服务器的 SSH 地址；跨网络时先配置可达路径，例如现有的 VPN / ZeroTier 网络。

在服务器上确认以下命令可执行：

```sh
python3 --version
codex --version
codex login status
```

Codex 的账号与模型凭证保留在服务器，不需要复制到 iPad。服务器的登录 Shell 环境需要能找到 `python3` 和 `codex`。

### 2. 获取代码并安装

```sh
git clone https://github.com/raycao871218/code-pax.git
cd code-pax
open CodePax.xcodeproj
```

1. 等待 Xcode 下载 Swift Package 依赖，选择 **CodePax** Scheme。
2. 运行模拟器可先检查界面；安装真机时，在 **CodePax → Signing & Capabilities** 选择自己的开发者 Team。若应用标识冲突，改用自己的唯一 Bundle Identifier。
3. 选择已连接的 iPad，按系统提示完成开发者模式、设备信任等设置，运行安装。
4. 需要从命令行构建或运行测试时，参阅 [开发与验证](docs/development.md)。

工程和依赖锁定文件已纳入仓库，首次拉取无需运行工程生成器，也不需要 CocoaPods 或 XcodeGen。

### 3. 连接并开始工作

1. 在连接页填写服务器名称、地址、端口、用户名和密码；可选择记住密码。点击“保存服务器设置”后，在服务器卡片页点击卡片连接。
2. 首次连接时核对 App 显示的 SSH 主机指纹。可在服务器上运行：

   ```sh
   for key in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$key" -E sha256; done
   ```

3. 连接后自动部署桥接脚本并准备工作区。已有历史按项目显示，也可新建项目聊天。
4. 在输入区选择模型、推理强度和权限，然后发送任务。右上角终端图标打开全屏终端。
5. 代理、模型刷新、后台更新等入口位于工作区设置；需要代理时填写实际可用的 HTTP / HTTPS 代理地址。

App 只支持密码认证，目前不支持私钥、SSH Agent、键盘交互认证或双因素登录。

## 常用操作

| 操作 | 入口或快捷键 |
| --- | --- |
| 发送消息 | 回车或 ⌘↵；中文输入法选词时不会提交 |
| 换行 | ⇧↵ |
| 新建聊天 / 搜索聊天 | ⌘N / ⌘K |
| 打开终端 | 工作区右上角终端图标，或 ⌘⇧T |
| 收起 / 结束终端 | 打开终端默认可输入；“收起”保留当前会话，重新打开自动聚焦；终端菜单里的“结束终端”只关闭该 PTY |
| 终端快捷键、字号 | 底部提供 Esc、Tab、Ctrl-C、Ctrl-D、方向键与键盘开关；菜单可隐藏快捷键栏、调字号和清屏 |
| 重命名、置顶、归档聊天 | 长按侧栏会话；右上角菜单可进入“已归档聊天”恢复 |
| 更换皮肤、配色和角色 | 工作区设置 → 外观 → 配色与自定义头像；连接页左上角外观菜单也可进入 |
| 读取完整内容 | 点击消息、执行输出或差异下方的“查看完整内容” |

Usage 剩余比例 **低于 10% 为红色，10% 至不足 20% 为黄色，20% 及以上为绿色**。未取得额度时显示灰色；账号不提供的明细会标为暂不可用。

## 配色与自定义角色

提供 **紫藤、海蓝、青竹、樱粉、琥珀、石墨** 六组配色。角色主题同步调整背景、气泡和强调色，经典工作台调整强调色；皮肤、配色和深浅色分别保存，切换立即生效。

头像可从照片或文件导入；动作支持 **GIF、APNG 或 2×2 四帧图**，可预览、以 0.5–2× 调速和恢复默认。素材保存在本机，重新启动仍可使用，不修改桌面图标。只导入头像时保持静态；只导入动作时第一帧作为静态头像。

聊天中只有当前回合最新回复播放动作，历史头像保持静态；系统开启“减少动态效果”或应用进入后台时暂停播放。左上角保留文字标题，不显示 Logo。

完整步骤与可复制模板见 [自定义头像与动作](docs/avatar-customization.md)。

## 文件与内容限制

| 类型 | 当前限制或行为 |
| --- | --- |
| 聊天附件 | 每次最多 8 个，单个最多 20 MB；图片走模型原生图像输入，其他文件交给服务器工具读取。 |
| 项目文件下载 | 单个最多 100 MB，经 SFTP 下载并校验 SHA256；支持预览与保存／分享。 |
| Markdown 文件 | 4 MB 以内支持内置格式化阅读，支持 UTF-8 与带 BOM 的 UTF-16；过大或编码无法识别时回退系统预览。其他格式由 Quick Look 处理。 |
| 自定义角色素材 | 单个最多 16 MB，动图最多 48 帧；四帧图需为正方形 2×2 排列、边长至少 128 像素且为偶数，建议使用更清晰的 1024 或 1536 像素图片。 |
| 聊天与历史 | 主聊天显示最近 40 条消息的预览，预览约 4000 字符；更早记录可在历史页浏览，完整正文按最多 24000 字符分段读取。 |
| 旧版已丢失的长内容 | 只能在原始 CLI 历史仍可用时重新同步恢复。 |

附件保存到当前项目的 `.codex-ipad-attachments/`。在 iPad 上移除待发送附件不会删除服务器文件；文件格式能否被模型实际处理，取决于服务器工具和权限。

## 连接、后台与数据

```text
iPad Code Pax
  ├─ SSH PTY ───────────────────────→ 远端交互式 Shell
  └─ SSH 请求 → Python 桥接后台 → 私有 Unix socket / SQLite
                                    └─ stdio JSON-RPC → Codex App Server
```

- 桥接脚本使用 Python 标准库，不额外开放 TCP 服务端口，也不要求 sudo。
- 当前桥接版本为 **0.11.4**，协议版本为 **2**。App 与桥接脚本独立编号，不要求版本号相同。
- Codex CLI 优先从服务器的 `PATH` 查找；SSH 环境未配置该路径时，也会检查 `~/.local/bin`、`~/.npm-global/bin`、`~/bin`、`/opt/homebrew/bin` 和 `/usr/local/bin`。
- 后台保存在 `~/.local/share/codex-ipad/`，目录权限 0700、socket 权限 0600。该路径、既有 Bundle Identifier 和钥匙串服务标识为兼容旧安装而保留。
- 已保存密码保存在设备钥匙串，绑定服务器、端口、用户和配置；主机指纹也保存在钥匙串。关闭记住密码或删除服务器会移除相应凭据。
- 对话页面处于前台时，网络恢复或回到 App 会尝试自动重连；首页不自动重连，重新启动 App 进入首页后需点击服务器卡片连接。手动断开会关闭自动重连。
- Codex 任务运行在服务器后台，断开 iPad 连接后仍可继续。iPad 的同步和终端连接受系统后台限制，不能据此保证终端里的任意进程一直运行。
- 空闲旧后台会自动更新；有运行中、待审批或结果不明的任务时暂缓更新。处理完后可在设置中“重新准备 / 应用更新”，不会为更新强制结束任务。
- 服务器重启会中断活动任务。重新连接后保留历史，不会自动重跑任务。

## 已知范围与排查

- 工作区目录选择默认限制在服务器用户 Home 范围内；这不是 SSH 账号权限隔离。自定义根目录通过桥接脚本的 `--root` 参数配置；已有后台不会因再次执行 `ensure` 而切换根目录，需要在无活动任务时先停止后台再启动。
- 仍在外部 CLI 运行的会话不会自动接管，应在原客户端完成后再刷新续聊。置顶、重命名和归档信息由桥接层保存，不修改 CLI 归档状态。
- `already has an active writer` 表示同一会话的写入权仍被另一 Codex 客户端占用，即使回复已经结束也可能继续占用。打开会话和同步状态时会预检查服务器上同一 Codex Home 的写入锁，提前提示占用并禁用发送；退出另一端会话后点击“重新检查”。不支持检测的环境仍以实际恢复会话结果为准，检测后的占用变化也会在发送时校验。急需工作可在同一项目新建聊天。
- 未送达或结果待确认消息的“重试”位于该条消息下方，使用原内容、附件、模型设置和操作 ID；新草稿单独保留。明确未发送的消息允许重试，结果不确定的请求先核对服务器记录，不自动重复执行。
- 模型列表及 Usage 来自服务器账号；列出模型不代表该账号一定有执行权限，部分历史会话可能没有 token 明细。
- 结果不确定的消息应先刷新或使用原操作 ID 重试，核实状态后再清除待确认记录，避免重复执行。
- 遇到连接失败，依次检查网络可达性、iPad 本地网络权限、SSH 密码认证和主机指纹；工作区未就绪时检查服务器能否运行 `codex app-server`。
- 当前尚无推送通知、私钥登录和文件编辑器。项目主要通过源码与 Xcode 真机安装进行测试，TestFlight 发布资料与配置尚未完成。
